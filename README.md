# Portfolio

A static, single-page portfolio for Gabriella Miwa. The page introduces Gabriella as a software developer, links to her GitHub, LinkedIn, and email, highlights selected projects, and lists skills.

## Featured projects

- **OrderMaze Expedition** — a six-level game with number and letter sequences.  
- **Employment-Management** — an application for managing employees and projects.  
- **French Verb API** — an API built with Flask and MongoDB.  
- **Accounts-Payable** — software for managing accounts payable for a small company.

Each project card links to its GitHub repository.

## Technologies

- HTML and CSS  
- Bootstrap 5.3.2  
- Bootstrap Icons 1.11.2  
- Font Awesome 6.0.0-beta3

The stylesheet and image assets are stored in the repository. Bootstrap and icon styles are loaded from CDNs, so they require an internet connection when viewing the page.

## Project structure

```
.
├── index.html      # Portfolio page and project information
├── styles.css      # Page styling
└── img/            # Avatar and project images
```

## View locally

Open `index.html` in a web browser. No build tools or package installation are required.
